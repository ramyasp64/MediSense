# Supervisor Tasks

This folder documents every task assigned by my thesis supervisor during the MediSense thesis supervision.
Each subfolder corresponds to one round of feedback, named by date and topic.

The core MediSense model, source code, and results live in `src/`, `scripts/`, and `experiments/`
at the repository root and are unaffected by this folder.

## Structure

| Folder | Date | Task |
|---|---|---|
| `day1_signal_visualization_and_literature/` | September 2026 | Signal morphology visualizations and literature gap analysis |
| `day2_baseline_challenge/` | October 2026 | Baseline challenge: prove bearing pretraining has domain-specific value |

## How this folder evolves

Each time my supervisor assigns a new task or round of feedback, a new dated subfolder is added here
with its own README, scripts, results, and figures. Nothing in this folder modifies the main MediSense
experiment pipeline or model weights.
